# 🖼️ Responsive Image Gallery

A modern, responsive, and interactive image gallery built using **HTML5, CSS3, and JavaScript**.

The project includes category-based image filtering, smooth hover effects, a full-screen lightbox, previous/next navigation, responsive layouts, and keyboard controls.

---

## 📌 About The Project

This project was created as a frontend development project to practice building an interactive and responsive user interface using vanilla HTML, CSS, and JavaScript.

Users can browse images, filter them by category, open images in a lightbox, navigate between images, and use keyboard shortcuts for a smoother browsing experience.

---

## ✨ Features

- 🖼️ Responsive image gallery
- 🏷️ Category-based image filtering
- 🔍 Full-screen lightbox viewer
- ⬅️ Previous image navigation
- ➡️ Next image navigation
- ❌ Close lightbox button
- 🖱️ Image hover effects
- ✨ Smooth CSS transitions and animations
- ⌨️ Keyboard navigation
- 📱 Mobile-friendly responsive design
- 💻 Tablet and desktop layouts
- 🔄 Continuous image navigation
- 🎨 Clean and modern user interface

---

## 🗂️ Image Categories

The gallery currently contains the following categories:

- **All**
- **Nature**
- **City**
- **Animals**

The filtering system allows users to display only the images belonging to the selected category.
